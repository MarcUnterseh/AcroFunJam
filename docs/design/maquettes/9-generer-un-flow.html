Story 9 « Générer un flow » : maquette

Écran de docs/design/ecrans/9-generer-un-flow.md, avec les valeurs de @acrofunjam/ui-tokens (aucun token nouveau ; une icône nouvelle, « station »). Chaque état est montré à 320 px puis sur grand écran ; les cadres réagissent à leur propre largeur.

Le formulaire et le résultat alternent sur la même page : le résultat remplace le formulaire, « Modifier les critères » le fait revenir. Libellés : ceux validés le 2026-11-19 ; ceux marqués « proposé » dans la spécification (« Critères du flow », « 1 choisie », « Description »…) restent à confirmer. Le contenu inchangé est remplacé par un repère en pointillés.

0. Accès depuis le catalogue

« Générer un flow », bouton secondaire, premier des actions du catalogue, pour tout le monde. « Proposer une pose » reste la seule action primaire.

1. Formulaire initial

3 transitions, « Débutant » / « Débutant » présélectionnés, repli des étiquettes fermé et sans compte. Une seule action primaire.

2. Repli des étiquettes ouvert, une case désactivée

« lunaire » demandée : cochée dans le premier groupe, désactivée et marquée « (demandée) » dans le second (fond désactivé, contour tireté, mot). Le compte figure dans le résumé du repli.

3. Génération en cours et autres états du formulaire

Pendant la génération, seul le libellé du bouton change (« Génération du flow… », aria-disabled, curseur d'attente). Incident réseau : alerte erreur avec « Réessayer ». Étiquette retirée : alerte information, repli rouvert. Étiquettes non chargées : note information à la place du repli.

4. Flow de 3 étapes avec une washing machine

Throne → Star → Star (Ninja Star, washing machine) → Folded Leaf, plafonds « Avancé » / « Avancé ». Les poses sont des stations sur un rail pointillé (lever au départ, coucher à l'arrivée) ; les transitions des cartes. Étiquettes de la transition dans la carte, celles de la pose sur sa station. Description repliée.

5. Même flow ressorti

Un seul flow possible (Throne → Bird). Alerte information entre le résumé et les critères ; le flow reste affiché tel quel.

6. Critères trop restrictifs, avec pistes

2 transitions, « Débutant » / « Débutant », sans « vrille » : les pistes « moins de transitions », « des plafonds de difficulté plus hauts » et « moins d'étiquettes exclues ». Pas de rouge : ce n'est pas une erreur. « Modifier les critères » est la seule action, donc primaire.

7. Catalogue insuffisant

Ce n'est pas la faute des critères : pas de récapitulatif ni de pistes, un lien-bouton secondaire « Voir le catalogue » (comme la page « pose introuvable »).
