Générer un flow sur mobile (story 9b)

Maquette statique de docs/design/ecrans/9b-generer-un-flow-mobile.md. Chaque écran est montré à l'aube (clair) puis la nuit (sombre), dans un cadre de 360 dp. Les cadres « déroulés » montrent tout le contenu défilant ; la barre basse, elle, reste fixée en bas de l'écran. Libellés réels des scénarios ; « Diminuer / Augmenter le nombre de transitions », « Description », « Nouveau flow généré. » sont proposés.

1. Critères (ouverture sans flow gardé)

Présélection : 3 transitions, « Débutant » / « Débutant », aucune étiquette. Compteur − / + (48 dp), tuiles 2 × 2, repli fermé, « Générer un flow » dans la barre basse. Écran déroulé.

2. Critères, étiquettes ouvertes

Défilé jusqu'aux étiquettes. « lunaire » demandée : cochée dans le premier groupe, désactivée « (demandée) » dans le second ; compte « 1 choisie » dans le résumé. Pastilles de 48 dp.

3. Le flow : 3 étapes, dont une washing machine

Rappel du spotter au-dessus du départ, jamais replié. Numéro d'étape 64 dp (sunStrong), nom de transition 28 dp, nom de pose 40 dp en texte simple. Récapitulatif des critères en fin d'écran. Barre basse : « Modifier les critères » à gauche, « Générer un autre flow » à droite, écart de 24 dp. Écran déroulé.

4. Après « Générer un autre flow » : message éphémère (Q223, proposé)

Le nouveau flow s'affiche depuis le haut ; le message se pose au-dessus de la barre, sans la couvrir, 10 s (délai recommandé par Android ; pas de délai avec un lecteur d'écran). « Revenir au flow précédent » rétablit le flow d'avant et ses critères.

5. Critères trop restrictifs

Sur l'écran des critères, le panneau remplace le formulaire ; « Modifier les critères » devient l'action principale de la barre. Pistes adaptées : ici une étiquette exclue.

6. AcroFunJam injoignable pendant « Générer un autre flow »

Le flow affiché ne bouge pas ; le message d'erreur se pose au-dessus de la barre, là où le doigt vient de toucher. « Générer un autre flow », juste dessous, sert de réessai. Aucun message éphémère.

7. Police du système à ×1,6 (aube seulement)

Texte ×1,6, titres plafonnés à ×1,25, noms de pose et numéros inchangés (typography.maxFontScale). Les plafonds passent en liste verticale, la barre du flow s'empile (« Modifier les critères » au-dessus, « Générer un autre flow » sous le pouce). À gauche, compteur à 1 : « − » désactivé (fond disabledSurface, contour tireté).
